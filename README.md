# Octavio Ramos | Turismo
## Descripción
Este sitio web fue desarrollado como proyecto final del curso de Desarrollo Web y forma parte de mi marca personal como creador de contenido sobre turismo, viajes y voluntariados.
El objetivo es ofrecer información útil para turistas y viajeros, actuar como intermediario entre clientes y vendedores, guías y turistas, hospedajes y huéspedes. Combinando un diseño moderno, responsive, y una experiencia de navegación clara e intuitiva.
